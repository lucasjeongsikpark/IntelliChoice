## Recording Attendance

Mark each enrolled student present as they check in for their session block. A
student with no record for the week is treated as absent, never as present, so
prompt recording matters.

## Handling a Blocked Session

When a student's week is blocked by absent or unknown attendance, they'll be offered
the choice to acknowledge the absence or ask you to review it. Review requests
arrive as an approval request you can approve or decline.

## Correcting Attendance

If a parent reports an attendance error, update the record for that week directly;
corrections should happen before the student's next pre-exam attempt where possible.

## Absence Patterns

If a student is absent for more than two consecutive weeks, note it in your monthly
report so the regional office is aware.
