# Kumon US public curriculum reference

This folder is a **reference only** for the public Kumon topic/level progression.
See `source_manifest.yaml`.

## Permitted use (SPEC §5.7.1)

- Public level names
- Public topic names
- Public concept progression
- Reference use for an internal curriculum taxonomy

## Not permitted

- Reproducing official worksheets
- Creating derivative copies by changing only numbers
- Copying official explanations
- Implying official affiliation or certification
- Scraping private curriculum tables

Nothing in this folder is executed or served to users. `curriculum_mapping.yaml` links
public topic names to `../internal_math/topics.yaml` topic IDs so the internal taxonomy's
provenance is traceable; all actual question content lives in `internal_math/` and
`packages/curriculum`, authored independently of any official Kumon material.
