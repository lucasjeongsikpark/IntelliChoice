# Attendance Policy

DRAFT — NOT APPROVED FOR PRODUCTION
Synthetic content for development and evaluation only.

## Why Attendance Gates Study

A student cannot start the week's pre-exam until attendance for that week is marked
present. This keeps the adaptive study plan tied to actual session participation.

## If Attendance Is Marked Absent

If a student is marked absent for the week, the platform blocks that week's session
and offers to acknowledge the absence or ask the branch manager to review it.

## If Attendance Is Unknown

If no attendance record exists yet for the week, the platform treats it the same as
absent - unknown attendance is never treated as present.

## Correcting a Mistake

If you believe attendance was recorded incorrectly, contact your branch manager, who
can review and correct the record for that week.
